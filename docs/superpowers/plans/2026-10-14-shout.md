# Shout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local, offline WisprFlow-style dictation app for Windows (hold Ctrl+Win, speak Hungarian or English, text is pasted), shipped as `Shout.exe` plus `ShoutSetup.exe`.

**Architecture:** A single Python process.
- PySide6 owns the UI (tray icon, non-activating pill overlay, main window).
- A pynput low-level keyboard hook feeds a pure hotkey state machine.
- sounddevice records 16 kHz mono into memory.
- faster-whisper transcribes on a worker thread (CUDA when available, CPU otherwise).
- The result is pasted via clipboard + Ctrl+V, then the old clipboard is restored.

**Tech Stack:** Python 3.14, PySide6-Essentials 6.12, faster-whisper 1.2.1 (CTranslate2 4.8.3), sounddevice 0.5.6, pynput 1.8.2, PyInstaller 6.22, Inno Setup 6.

**Spec:** `docs/superpowers/specs/2026-10-14-shout-design.md`

## Global Constraints

- Windows 10/11 x64 only. Per-user install, no admin rights.
- No network calls except the first-run downloads: Hugging Face model and PyPI NVIDIA wheels (`nvidia-cublas-cu12==12.9.2.10`, `nvidia-cudnn-cu12==9.27.0.42`).
- Default hotkey: hold Ctrl+Win = push-to-talk; Ctrl+Win+Space = hands-free; Esc = cancel; holds < 0.3 s are ignored.
- Language mode is one of `auto` (pick the more likely of hu and en), `hu` or `en`.
- Data lives in `%APPDATA%\Shout` (settings.json, history.jsonl). Models and CUDA libraries live in `%LOCALAPPDATA%\Shout`. Audio is never written to disk.
- UI copy is Hungarian and contains no em-dashes or en-dashes. Fonts are Geist and Geist Mono. Colours are off-black/off-white monochrome. Light and dark mode follow the system. Icons come from Phosphor.
- No commits (the folder is not a git repo; the user has not asked for one).

## File map

| File | Responsibility |
|---|---|
| `engine.py` | CUDA runtime fetch, `Recorder` (mic to numpy plus level callback), `Transcriber` (model load, hu/en pick, transcribe), `clean_text`, `pick_language` |
| `keys.py` | `Hotkey` pure state machine, `KeyHook` (pynput wrapper with suppression), `paste_text`-side helpers: `send_ctrl_v`, `mask_start_menu`, `wait_modifiers_released` |
| `ui.py` | Theme tokens and QSS, `Pill` overlay, `MainWindow` (History and Settings), keycap widget |

| `assets/` | `shout.ico`, Geist TTFs, Phosphor SVGs |

| `build.ps1` | PyInstaller one-folder build, then ISCC |

### Task 1: Engine (ASR core)

**Files:** Create `engine.py`, `test_shout.py`

**Interfaces (produces):**
- `pick_language(probs: list[tuple[str, float]]) -> str`: returns `'hu'` or `'en'`, whichever has the higher probability (ties go to `'hu'`).
- `clean_text(text: str) -> str`: collapses whitespace, strips, and returns `''` for known hallucinations or punctuation-only output.
- `ensure_cuda(progress: Callable[[str, float], None]) -> bool`: True if CUDA is usable; downloads and extracts the DLLs on first run.
- `class Transcriber(model: str = 'auto', progress=None)`:
  - `.load()` blocks.
  - `.device: str`, `.model_name: str`.
  - `.transcribe(audio: np.ndarray, language: str, hotwords: str) -> str`.
- `class Recorder(device: int | None, on_level: Callable[[float], None])`:
  - `.start()`.
  - `.stop() -> np.ndarray` (float32, 16 kHz).
  - `Recorder.input_devices() -> list[tuple[int, str]]`.

### Task 2: Hotkey state machine and key I/O

**Files:** Create `keys.py`; modify `test_shout.py`

**Interfaces (produces):**
- `class Hotkey`:
  - `feed(vk: int, down: bool, t: float) -> tuple[str | None, bool]` returns `(event, suppress)`.
  - `event` is one of `'start'`, `'handsfree'`, `'stop'`, `'cancel'`, `None`.
  - `.state` is one of `'idle'`, `'ptt'`, `'free'`, `'wait'`.
- `class KeyHook(on_event: Callable[[str], None])`: `.start()`, `.stop()`. Ignores injected events (LLKHF_INJECTED) and suppresses Space and Esc when the state machine consumes them.
- `mask_start_menu()`, `send_ctrl_v()`, `wait_modifiers_released(timeout=2.0) -> bool`.

- [ ] Step 1: Failing tests:

```python

def run(h, seq):
    return [h.feed(vk, down, t)[0] for vk, down, t in seq]

def test_ptt():
    h = Hotkey()
    assert run(h, [(VK_LCONTROL, 1, 0), (VK_LWIN, 1, .1), (VK_LWIN, 0, 1.5), (VK_LCONTROL, 0, 1.6)]) == [None, 'start', 'stop', None]

def test_short_hold_cancels():
    h = Hotkey()
    assert run(h, [(VK_LCONTROL, 1, 0), (VK_LWIN, 1, .1), (VK_LWIN, 0, .2)]) == [None, 'start', 'cancel']

def test_other_key_cancels_and_waits_for_release():
    h = Hotkey()
    ev = run(h, [(VK_LCONTROL, 1, 0), (VK_LWIN, 1, .1), (0x25, 1, .5), (0x25, 0, .6), (VK_LWIN, 0, .7), (VK_LCONTROL, 0, .8)])

    assert run(h, [(VK_SPACE, 0, .3), (VK_LWIN, 0, .4), (VK_LCONTROL, 0, .5)]) == [None, None, None]
    assert run(h, [(VK_LCONTROL, 1, 5), (VK_LWIN, 1, 5.1)]) == [None, 'stop']

def test_no_start_with_extra_modifier():

    assert run(h, [(0xA0, 1, 0), (VK_LCONTROL, 1, .1), (VK_LWIN, 1, .2)]) == [None, None, None]
```

### Task 4: UI and wiring

**Files:** Create `ui.py`, `shout.py`

**Interfaces:**
- `ui.Pill`:
  - `.show_recording()`, `.set_level(float)`, `.show_handsfree()`, `.show_working()`, `.show_message(text, ms=1800)`, `.hide_pill()`.
- `ui.MainWindow(settings: dict, on_settings_changed: Callable[[dict], None])`:
  - `.set_history(items: list[dict])`, `.add_history(item)`, `.set_status(text)`.
- `shout.py` wiring, all on the Qt main thread via signals:
  - `start` → `Recorder.start()` + `pill.show_recording()` + `mask_start_menu()`.
  - `stop` → `audio = Recorder.stop()`, worker thread `Transcriber.transcribe`, result signal → `clean_text` → paste → history append.
  - `cancel` → stop and discard, then hide the pill.
